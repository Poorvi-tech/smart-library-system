# Smart Library System

A frontend-only React project showcasing a modern digital library interface with login, dashboard, book search, QR scan simulation, and book details.

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`

## Structure

- `src/components` - reusable UI components
- `src/pages` - page screens
- `src/data` - mock book data
- `src/assets` - asset folder for future images or icons
